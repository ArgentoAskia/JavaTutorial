## Effective Java 14: 考虑实现 Comparable 接口

1. 当你的类是一个值为主的类而非引用为主(类似于基本类型)或者需要为此类提供比较、排序能力的时候，考虑使用`Comparable`接口

3. 实现此接口的规则：-1、0、1规则 
4. 强烈建议(compare To (y) == 0) == (x . equals (y)), 若违反了这个条件，都应该明确在文档中予以说明, 推荐使用这样的说法"注意：该类具有内在的排序功能，但是与 equals 不一致“
5. compareTo()方法内部各个字段的比较优先使用各个字段类型实现得到CompareTo()方法(递归调用CompareTo()), 如果字段本身不实现Comparable接口时，考虑使用Comparator临时定义该字段的比较关系
6. 在compareTo()中使用关系操作符<和>是非常烦琐的，并且容易出错，因此不再建议使用, 归咎其原因是关系操作符<和>只能比较出二元关系，也就是true和false的情况, 而compareTo()存在大于等于小于三种情况，因此你需要额外做判断, 更别说对于浮点性，可能还存在精度问题，Effective Java中建议, 对于基本类型，使用其包装器类提供的compare()静态方法, 对于引用类型, 继续调用引用类型的compareTo(), 而如果引用类型没有实现Comparable时考虑使用Comparator决定其临时关系
